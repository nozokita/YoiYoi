# YoiYoi デザイン方針 v3.0
> 最終更新: 2026.05.29
>
> 対象: Lean MVP。詳細な機能要件は [SPEC.md](./SPEC.md) を正とする。

## 体験の軸

YoiYoi は、楽しく飲む時間を損なわず、無理しないペースでアルコール摂取量を記録できるアプリである。20〜70歳の大人が世界中で長く使えるよう、画面は「叱る」「判定する」よりも、「いまの状態がわかる」「すぐ記録できる」「次の小さな行動を思い出せる」を優先する。

- 落ち着いたクリームの背景、インク色の本文、コーラルの行動アクセントを基調にする。
- 無料アプリとして将来広告枠が入っても、主要行動と記録の読み取りを邪魔しない余白を残す。
- 純アルコール量は明瞭に示すが、安全量または追加で飲める量とは表現しない。
- 日英どちらでも意味が変わらず、狭い幅で収まる文言を選ぶ。
- 初回導線、App Store、設定では、記録が端末内だけに保存されることを明確に伝える。

## 言語

- MVP は日本語と英語を同等に扱う。
- 言語選択は初回導線の先頭に置き、設定画面からいつでも変更可能にする。
- 将来の追加言語でレイアウトが壊れないよう、固定幅を多用せず折り返しと可変高さを許容する。
- 保存データは表示言語に依存しない識別子を使用する。

## カラーとタイポグラフィ

| 役割 | 方針 |
|------|------|
| 背景 | `cream`。紙のような暖かさを持つ低彩度ベース |
| 主アクセント | `coralRed`。記録、保存、重要な選択だけに使う |
| カード | `surfaceElevated`、角丸 24-28pt、薄い境界線、ニュートラルな影 |
| 本文 | `charcoal`、大人向けの落ち着いた高コントラスト |
| 成功・安心 | `mintGreen` / `mintLight`。休肝日や安定したペースの表現 |
| 注意 | `amber80` / `warmCoral`。強い警告ではなく、行動提案とセットで使う |

大きな数値は読み取りやすさを優先する。日本語と英語のフォント差は `AppFonts` と `SupportedLanguage` の責務とし、追加言語も同じ経路で実装する。アイコンは SVG を基本とし、装飾目的で多用しない。ラベルと余白で意味が伝わる場合、アイコンを増やさない。

## ナビゲーション

メインは 3 タブと中央の記録ボタンで構成する。

| 要素 | 役割 |
|------|------|
| ホーム | 今日の純アルコール量、設定した目安との差、クイック記録、コーチ表示 |
| カレンダー | 日別・週別の記録振り返り |
| 中央ボタン | 詳細なドリンク記録シートを開く |
| 設定 | 目安、通知、言語、プライバシーポリシー、免責 |

下部バーは `safeAreaInset(edge: .bottom)` で配置し、内容のスクロール領域を圧迫しない。選択状態は色とラベルの両方で区別する。

## 初回体験

### 現在の必須導線

| 順序 | 画面 | 必須表示 |
|------|------|----------|
| 1 | 言語選択 | `日本語` / `English`。この画面では言語選択だけに集中する |
| 2 | 性別と目安設定 | 参考値でありユーザーが調整できること |
| 3 | 相棒モード選択 | 記録とペースに寄り添うコーチの話し方 |

端末内保存の訴求は言語選択画面には置かず、初回導線内の説明、App Store、設定のデータとプライバシー領域で明確に表示する。

## ホーム

ホームは次の順序で構成する。

1. ヒーロー: 今日の純アルコール量と設定した目安。数字を最優先で読ませる。
2. コーチカード: 端末上の生成または定型メッセージ。押しつけず、次の小さな行動を提案する。
3. すぐ記録: よく飲むドリンク最大 6 件と、最近の異なる記録最大 5 件。
4. 飲み会モード: 水分補給通知など、実装されたセッション機能のみ。

### 数値表現

| 日本語 | English |
|--------|---------|
| 設定した目安まであと28g | 28g until your set guide. |

目安超過後は事実を落ち着いて表示し、罪悪感を促す言葉や追加摂取を勧める言葉を避ける。

### クイック記録

- お気に入りと最近の記録は視覚的に分離し、どちらを押したか明確にする。
- ワンタップ保存後は 5 秒間、画面下部に取り消し操作を表示する。
- 詳細を確認してから保存したいユーザーには中央記録ボタンのシートを提供する。
- ビール、日本酒、ワインなどは量の差が大きいため、プリセット選択後も容量と杯数を自然に調整できる UI にする。

## カレンダー

- 月表示から日別記録にアクセスできる既存構成を維持する。
- 記録のない日を否定的に扱わず、振り返りやすい余白と階層を保つ。
- 日別詳細は種類、容量、度数、純アルコール量を一覧できるようにする。

## 設定

設定画面に残す導線は次のとおり。

| セクション | 内容 |
|-----------|------|
| 言語 | 日本語 / English の切替。将来の選択肢追加に耐える一覧形式 |
| 目安 | 1 日・1 週間のユーザー設定値 |
| 通知 | ローカル通知の設定 |
| 情報 | プライバシーポリシーリンク、アプリ版、免責 |

免責は「本アプリは医療アドバイスを提供するものではありません」と簡潔に常時表示する。

## 公開用表示

App Store の説明とスクリーンショットでは、次の価値を日英で揃える。

| 日本語 | English |
|--------|---------|
| 記録は端末だけに保存 | Records stay on your device |
| よく飲むドリンクをワンタップ記録 | Log favorites in one tap |
| 設定した目安まであと28g | 28g until your set guide |
| 飲み会中は水分補給をリマインド | Hydration reminders while you drink |

## 実装時の確認

- Dynamic Type で主要数値とボタンの文言が読めること。
- 日本語と英語の両方で、ホーム、初回画面、設定の主要表示が切れないこと。
- 20〜70歳の大人が見ても安っぽく見えない、低彩度・高コントラスト・十分な余白になっていること。
- ライトモード固定の現在方針と、クリーム背景が全画面に適用されること。
- クイック記録の保存と取り消しで誤操作が回復できること。
