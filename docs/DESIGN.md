# YoiYoi デザインシステム v5.0
> プロフェッショナルデザイン確定版 — 2026.03.21

## デザインコンセプト

### ビジュアルディレクション
参照: Education Point アプリのレイアウトパターンを YoiYoi のブランドカラーで再構築。

**コアパターン:**
- **ウェーブヒーロー**: 各画面上部にテーマ色のウェーブ背景 + キャラクター/アイコン
- **カード中心レイアウト**: 情報は全てカード内に収める。カードは白背景 + テーマ色シャドウ
- **グラデーションアクセントカード**: 重要な情報は横長グラデーションカード（左テキスト + 右アイコン）
- **上部リッチ → 下部クリーン**: 画面上部はテーマ色で豊か、下部は cream 背景でスッキリ
- **一貫したナビゲーション**: 全画面で同じタブバー、同じ余白、同じカード半径

**AIっぽさを排除するルール:**
- 均等グリッドの機械的配置を避け、要素サイズに強弱をつける
- 余白を恐れない（詰め込まない）
- アイコンは絵文字で統一し、SF Symbols の無機質さを回避
- 数字は特大（48pt+）にして視覚的ヒエラルキーを明確に
- 直線的な区切り線は使わない。余白またはカードで区切る

### 画面構成の共通パターン

```

│   ウェーブヒーローエリア           │  ← テーマ色グラデ + 波型クリッピング
│   （タイトル + メイン情報）        │     高さ: 画面の約30-35%
│                                  │
│ ～～～～～～～～～～～～～～～～～  │  ← ウェーブカーブ（CustomShape）
│                                  │
│   コンテンツエリア                │  ← cream 背景
│   （カード群、ScrollView）        │     上部カードはヒーローに -24px 重なる

└──────────────────────────────────┘
```

### ウェーブシェイプ仕様

```swift
struct WaveShape: Shape {
    func path(in rect: CGRect) -> Path {
        var path = Path()
        path.move(to: .zero)
        path.addLine(to: CGPoint(x: 0, y: rect.height * 0.85))
        path.addCurve(
            to: CGPoint(x: rect.width, y: rect.height * 0.75),
            control1: CGPoint(x: rect.width * 0.35, y: rect.height * 1.05),
            control2: CGPoint(x: rect.width * 0.65, y: rect.height * 0.55)
        )
        path.addLine(to: CGPoint(x: rect.width, y: 0))
        path.closeSubpath()
        return path
    }
}
```

### カードスタイル定義

**① コンテンツカード（標準）**
```swift
// 白背景 + テーマ色シャドウ
.background(Color.white)
.clipShape(RoundedRectangle(cornerRadius: 24))
.shadow(color: themeColor.opacity(0.10), radius: 16, y: 6)
```

**② グラデーションアクセントカード（横長、参照デザインの科目カード相当）**
```swift
// テーマ色グラデーション + 右端にアイコン/絵文字
LinearGradient(
    colors: [themeColorLight, themeColor],
    startPoint: .leading, endPoint: .trailing
)
.clipShape(RoundedRectangle(cornerRadius: 20))
.shadow(color: themeColor.opacity(0.20), radius: 12, y: 4)
// 高さ: 72pt、左にテキスト、右に絵文字（32pt）
```

**③ フロストカード（オーバーレイ用）**
```swift
.background(.ultraThinMaterial)
.background(Color.white.opacity(0.85))
.clipShape(RoundedRectangle(cornerRadius: 24))
.overlay(
    RoundedRectangle(cornerRadius: 24)
        .stroke(Color.white.opacity(0.5), lineWidth: 1)
)
.shadow(color: themeColor.opacity(0.08), radius: 12, y: 4)
```

### ぷっくりボタン仕様

```swift
LinearGradient(
    colors: [Color("coralLight"), Color("coralRed")],
    startPoint: .top, endPoint: .bottom
)
.clipShape(RoundedRectangle(cornerRadius: 20))
.shadow(color: Color("coralDeep").opacity(0.3), radius: 12, y: 6)
// disabled 時: opacity 0.5、shadow なし
```

### 影ルール

- 影は**必ず**各画面のテーマ色から派生（グレーは使わない）
- ホーム: `coralRed.opacity(0.10)`
- カレンダー: `mintGreen.opacity(0.10)`
- フィード: `sunnyYellow.opacity(0.10)`
- 設定: `lavender.opacity(0.10)`

### アニメーション（MVP）

| アニメーション | トリガー | 実装 |
|-------------|--------|------|
| メーターリング描画 | 画面表示時 | `.trim(from:to:)` + `withAnimation(.easeOut(duration:1.2))` |
| ボタンタップスケール | タップ | `.scaleEffect` 0.95 → 1.0 |
| カード出現 | スクロール表示 | `.opacity` + `.offset(y:20)` transition、各カード 0.05s ずつ遅延 |
| リアクション追加 | タップ | `.scaleEffect` 1.3 → 1.0 + haptic |
| ヒーロー数字カウントアップ | 画面表示時 | Timer で 0 → 実数値まで 0.8s |

### タブバー仕様

```
┌──────────────────────────────────────────┐
│                                          │
│   🏠        📅       （＋）      🌍       ⚙️   │
│  ホーム   カレンダー           みんな    設定  │
│                                          │
└──────────────────────────────────────────┘
```

- フロスト背景（`.ultraThinMaterial`）
- **実装メモ:** システム `TabView` の `tabItem` は `Label("タイトル", systemImage:)` を使う（ヒット領域・Dynamic Type との整合）。ASCII 図の 🏠📅 等は情報設計の示意であり、コード上のアイコンと同一である必要はない。
- 中央の＋ボタンは **56pt 円形**、coralRed グラデーション、タブバーから **上に 16pt** 浮かせる
- 選択中タブ: `coralRed`、非選択: `greyText`
- ラベル: 10pt、SF Pro Rounded
- ＋ボタンの影: `coralDeep.opacity(0.3)`, radius 12, y 4

```swift
// 中央 FAB
Circle()
    .fill(LinearGradient(
        colors: [AppColors.coralLight, AppColors.coralRed],
        startPoint: .top, endPoint: .bottom
    ))
    .frame(width: 56, height: 56)
    .shadow(color: AppColors.coralDeep.opacity(0.3), radius: 12, y: 4)
    .overlay(
        Image(systemName: "plus")
            .font(.system(size: 24, weight: .bold))
            .foregroundStyle(.white)
    )
```

### App Store アイコン

確定ロゴ画像をそのまま 1024×1024 で書き出し。
iOS が自動的に squircle マスクを適用するため、角丸処理は不要。
四隅20%のマージンには重要な要素を配置しない（ロゴは中央寄りで問題なし）。

### App Store スクリーンショット配色

- 背景: 各画面のヒーローグラデーションをそのまま使用
- テキスト: 白（ヒーロー上）→ charcoal（cream 上）
- 端末フレーム: なし（フルブリード推奨）
- キャッチコピー配色: coralRed + pureWhite
